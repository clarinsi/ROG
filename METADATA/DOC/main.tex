\section{Introduction}

This document describes annotation layers and tags of the training corpus of
spoken Slovenian ROG \cite{verdonik2024c}.


ROG corpus consists of:
\begin{description}
  \item[ROG-SST,]  which includes selected GOS~2.1 transcriptions with manually
    assigned lemmas and morphosyntactic tags according to the MULTEXT-East
    annotation scheme, as well as annotations according to the Universal
    Dependencies annotation scheme (i.e. part-of-speech categories,
    morphological features and syntactic dependencies). ROG-SST is distributed
    as CONLL-U format\footnote{
      \url{https://universaldependencies.org/format.html}
    } (2014-2024) (.conllu files).
  \item[ROG-Art,] which includes all the annotation layers from the ROG-SST plus
    additional annotation layers for prosodic units, disfluencies and dialogue
    acts. ROG-Art is distributed as EXMARaLDA format (.EXB files)
    \cite{schmidtworner2014}. In addition to the .EXB files, .EXS files and
    Rog-Art.coma file are added for searching through the annotated corpus in
    the EXMARaLDA EXAKT concordancer, .TRS files \cite{barras2001transcriber}
    are added for viewing the transcriptions without annotations in the
    Transcriber, and .textGrid files \cite{boersma19922022} with additional
    prosodic annotations in the Praat (TeG folder) can be found in the ROG-Art
    folder.
\end{description}

This documentation provides information on annotation layers and tags for both
ROG-SST and ROG-Art subset.

\section{Data sources and file naming convention}

Both ROG-SST and ROG-Art consist of data published in GOS~2.1 corpus
\cite{verdonik2024a}\footnote{\url{ http://hdl.handle.net/11356/1863 }}, which
represents a merge of the:
\begin{itemize}
  \item GOS~1  \cite{verdonik2013}\footnote{
          \url{http://hdl.handle.net/11356/1863}} and
  \item selected data from the Artur 1 corpus \cite{verdonik2024b}\footnote{
          \url{http://hdl.handle.net/11356/1772}
        }.
\end{itemize}

\section{Lemmas}
Lemmas were first assigned automatically using the CLASSLA-Stanza model for
lemmatisation of standard Slovenian 2.0~\cite{tercon2023} and then manually
validated/corrected. The manual corrections followed the lemmatization
guidelines\footnote{\url{https://wiki.cjvt.si/books/05-lemmatization}}.

\section{MULTEXT-East morphosyntactic tags (xpos)}

Morphosyntactic tags in ROG-Art and ROG-SST were assigned automatically using
the The CLASSLA-Stanza model for morphosyntactic annotation of standard
Slovenian 2.0\footnote{\url{http://hdl.handle.net/11356/1767}} and then manually
validated/corrected. The tags follow the Slovene Multext-East Specifications
(v6)\footnote{\url{https://nl.ijs.si/ME/V6/msd/html/msd-sl.html}}.

\section{Additional}
In this tier corrections of transcription are annotated, e.g. when a word or
filler in the transcription is missing, e.g. `nnn' means that filler `nnn' is
missing in the defined segment.

Furthermore, lengthened phonemes in case of the lengthening are marked with
sign~(:) after the phoneme, e.g. `o(:)d' means that phoneme `o' in the word `od'
is lengthened.
\section{Disfluency annotations}
\subsection{vocalDisfluency}
Vocal dislfuencies are annotated. These disfluencies are manifested through
pronunciation or non-verbal/semi-verbal expressions. Tags are:

\begin{longtable}{|l|p{12cm}|}
  \hline
  \textbf{Tag}                & \textbf{Description}                                    \\
  \hline
  \endhead
  %
  \textbf{lengthening}        & A specific phoneme or syllable within a word may be
  extended beyond its typical duration, or an entire word may be articulated
  more slowly and with prolongation. If such prolongation does not signal the
  end of a syntactic-semantic unit or does not serve as a rhetorical figure, it
  can be classified as disfluency. The annotation of this phenomenon largely
  depends on auditory perception and the annotator's subjective judgement
  regarding whether the prolongation indicates that the speaker is pausing to
  gain time for speech formulation or not.                                              \\ \hline
  \textbf{silentPause}        & A silent pause in speech may or may not indicate
  disfluency. Speakers may use pauses between sentences or statements for
  rhetorical purposes, among other reasons. The boundary between these two
  functions is neither clear nor easily defined. As a general rule, pauses
  occurring within a semantic-syntactic unit or statement are more often
  considered as disfluencies, while those between statements or sentences are
  less frequently classified as such. Additionally, in slow speech, only pauses
  that are notably long are marked, whereas in fast speech, even brief pauses
  can be perceived as disfluency.                                                       \\ \hline
  \textbf{filledPause}        & In the Slovenian speech, the mid-central vowel
  /\textschwa/ is frequently used, and less commonly, the voiced consonants /m/
  or /n/, in a manner perceived as filler sounds or referred to as gap fillers.
  Such sounds are consistently annotated as filled pauses without exception.            \\
  \hline
  \textbf{nonlinguisticSound} & The speaker clears their throat, coughs, or produces a
  similar sound, indicating an issue with the speech apparatus.                         \\
  \hline
  \textbf{block}              & A speaker does not pronounce a particular word entirely
  fluently. There may be hesitation at the beginning, or a gap may be perceived
  in the pronunciation. However, the word is still produced in the correct form
  and the speaker does not restart the pronunciation.                                   \\ \hline
\end{longtable}

  mismatch that is not an established pattern, not even in conversation or

  \textbf{abandoned}               & The speaker does not complete a started structure,
  nor corrects or changes it, but instead, for example, leaves the turn to the

  annotated as abandoned.                                                                \\ \hline
  \textbf{repetition}              & The speaker repeats a word or a phrase two or more
  times consecutively, but not for the purpose of emphasis. Repetition can be
  accompanied by silent or filled pause or lengthening or not. Examples: da
  tisti ki ki `so the one that that'; bolj ali manj v eem v `more or less in uhm
  in'; ko igram glasbo ko igram glasbo pozabim na vse probleme `when I play
  music when I play music I forget all the problems'                                     \\ \hline
  \textbf{selfrepairPronunciation} & Speaker re-pronounces the word before it is fully
  articulated. Examples: b() bo `w() will; da() določene `spi() specific'                \\
  \hline
  \textbf{selfrepairLexicogrammar} & The speaker revises their speech by fully or
  partially replacing, adding, and/or omitting one or more words. Examples:
  nekam | nikoli `somewhere | never'; da človek ne poškodu() | da robot ne
  poškoduje `that human does not ha() | that robot does not harm'; v tej | v
  večini teh `in these | in most of these'                                               \\ \hline
  \textbf{selfrepairRestart}       & The speaker abandons the initiated structure and
  restarts the sentence and/or thought. The initial structure is neither
  completed nor revised but is entirely abandoned, and the speaker proceeds with
  a new structure, often rephrasing the content in a different manner. Examples:
  pa smešno je ker imajo | recimo enkrat sva hotela iti gledat `and it's funny
  because they have | for example once we wanted to go watching; glih je š() |
  letelo je mimo tega gorovja `exactly pass() | it flew right above these
  mountains'                                                                             \\ \hline
  \textbf{selfrepairComplex}       & Multiple disfluencies can accumulate one after
  another in a segment of text, or the speaker can change the planned structure
  of the sentence but does not correct all parts already spoken that are
  structurally connected to the revision, or does not complete the repair
  sequence. Such and other similar self-repairs that do not fit into any of the
  above categories are annotated as complex disfluencies. Example: to naše
  področje medijsko no medijsko je zelo široko področje novinarsko področje
  založniško bom tako rekla novinarsko zaro() založniško `this our field of
  media well media is a very broad field the field of journalism the field of
  publishing I'll put it this way journalist publi() publishing'.                        \\
  \hline
  \textbf{nonspecified}            & A disfluency that does not fit into any of the
  specified types.                                                                       \\ \hline
\end{longtable}

\section{prosodicUnits}
The boundaries between prosodic units were annotated manually according to
several prosodic parameters, including:
\begin{itemize}

  \item  pauses (the absence of speech, i.e., silence),
  \item  pitch reset,
  \item  intensity reset,
  \item  changes in tempo,
  \item  the presence of discourse markers,
  \item  breathing patterns (partially coinciding with pauses),
  \item  speaker turn-taking, and
  \item  the auditory perception of the human annotator.
\end{itemize}
The values for the parameters pitch reset, intensity reset, and tempo changes
were calculated on a syllable basis and served as supporting parameters for the
human annotators who annotated the prosodic breaks. The key parameter was the
auditory perception of the human annotator, irrespective of the calculated
parameter values.
\section{dialogActsPrimary}

primary function is annotated.

\section{textGrid tiers}

The TextGrid-files for prosodic analysis contain several tiers, including the
original speech text, values of selected parameters, as well as the manual
annotations of the prosodic units.

The individual tiers can be described as follows:
\begin{description}
  \item[Tier 1]	Contains the speaker ID (e.g., \#Artur-N-G5082) for each speaker
    turn.
  \item[Tier 2]	Contains the standardized transcription of the speech, imported
    directly from the Transcriber files.
  \item[Tier 3]	Contains the word segmentation of the speech in standardized
    form.
  \item[Tier 4]	Contains the annotation of discourse markers. If a token was
    manually recognized as a discourse marker, it was assigned the value “POS”.
  \item[Tier 5]	Contains the conversational transcription of the speech,
    imported directly from the Transcriber files.
  \item[Tier 6]	Contains the token ID for each individual token.
  \item[Tier 7]	Contains the word segmentation of the speech in conversational
    form.
  \item[Tier 8]	Contains the syllable segmentation of the conversational speech
    form.
  \item[Tier 9] Contains the phone segmentation of the conversational speech
    form.
  \item[Tier 10]	Contains the value for the parameter pitch reset. If pitch
    reset occurs, the value is ``POS'', if not, the value is ``NEG''. The pitch
    reset values are calculated according to the syllable-level segmentation
    from Tier 8.
  \item[Tier 11]	Contains the value for the parameter intensity reset. If
    intensity reset occurs, the value is ``POS'', if not, the value is ``NEG''.
    The intensity reset values are calculated according to the syllable-level
    segmentation from Tier 8.
  \item[Tier 12]	Contains the value for the parameter speech rate reduction. If
    the speech rate drops, the value is ``POS'', if not, the value is ``NEG''.
    The speech rate reduction values are determined according to the
    syllable-level segmentation from Tier 8.
  \item[Tier 13]	Contains the value for the parameter pause. If absence of
    speech is detected, the value is ``POS'', if not, the value is ``NEG''.  The
    pause values are determined according to the conversational word
    segmentation from Tier 7.
  \item[Tier 14]	Contains the value for the parameter speaker change. If a
    speaker turn is detected,  the value is ``POS'', if not, the value is
    ``NEG''. The speaker change values are determined according to the
    syllable-level segmentation from Tier 8.
  \item[Tier 15]	Contains the manually annotated prosodic units. Each non-empty
    segment represents one prosodic unit and contains the token IDs of all the
    tokens comprising a given prosodic unit.
\end{description}
